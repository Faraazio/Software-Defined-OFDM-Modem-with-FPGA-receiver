# Software-Defined OFDM Modem with FPGA Receiver

This is an implementation of a Python-based OFDM modem validating an FPGA OFDM receiver design. The implementation is based on the IEEE 802.11a standard with 64 subcarriers, a cyclic prefix of 16 samples, and QPSK modulation. It includes frame synchronization, channel estimation, and zero-forcing equalization, and supports simulation over both AWGN and multipath channels.

## Software Features

- Transmitter chain: bit generation, QPSK mapping, subcarrier allocation, IFFT, cyclic prefix insertion, preamble generation (STS and LTS).
- Receiver chain: coarse timing synchronization via STS autocorrelation, fine timing via LTS autocorrelation, channel estimation using LTS, zero-forcing equalization, QPSK demapping.
- Channel models: additive white Gaussian noise (AWGN), two-tap multipath channel.
- Performance evaluation: bit error rate (BER) versus signal-to-noise ratio (SNR) curves.
- Synchronization algorithms robust to multipath delay as long as delay spread is less than cyclic prefix.

## System Parameters

| Parameter                | Value   |
|--------------------------|---------|
| FFT size                 | 64      |
| Number of data subcarriers| 48     |
| Cyclic prefix length     | 16      |
| Modulation               | QPSK (Gray-coded) |
| Preamble                 | 10 short symbols (160 samples) + 2 long symbols with CP (160 samples) |
| Channel model            | AWGN, two-tap delay line |

## Transmitter

The transmitter performs the following operations:

1. **Bit generation**: `tx_bits` is a 3-dimensional array of shape `(frames, symbs, 2)`, where each frame contains `symbs` OFDM symbols, each symbol carrying `2` bits per QPSK symbol.

2. **QPSK mapping**: Bits are mapped to complex symbols using the standard Gray-coded QPSK constellation:

   $$
   s = \frac{1}{\sqrt{2}} \left( (1 - 2b_I) + j (1 - 2b_Q) \right)
   $$

   where $b_I$ and $b_Q$ are the two bits for the symbol. This maps bits 0 and 1 to +\frac{1}{\sqrt{2}} and -\frac{1}{\sqrt{2}} respectively.

4. **Subcarrier allocation**: The 48 data symbols are placed into a 64-point frequency-domain vector at indices 1 through 48. The DC subcarrier (index 0) and guard subcarriers (indices 49–63) are set to zero.

5. **IFFT**: The frequency-domain vector is transformed to time domain using an inverse fast Fourier transform (IFFT), resulting in 64 complex time samples.

6. **Cyclic prefix insertion**: The last 16 time samples are copied and prepended to form an 80-sample OFDM symbol.

7. **Preamble generation**:
   - Short Training Sequence (STS): 10 repetitions of a 16-sample short symbol, for a total of 160 samples. It is generated by IFFT of a predefined frequency-domain sequence with non-zero values at subcarriers $\pm 4, \pm 8, \pm 12, \pm 16, \pm 20, \pm 24$.
   - Long Training Sequence (LTS): a 32-sample cyclic prefix followed by two identical 64-sample long symbols, totaling 160 samples. The long symbol is the IFFT of a standard 64-point frequency sequence with values on all non-zero subcarriers.
   - The preamble is prepended to the stream of data symbols.

## Receiver

The receiver implements the following synchronization and equalization blocks:

1. **Coarse timing synchronization** using the STS periodicity. The received signal is autocorrelated with a delay equal to the short symbol length (16 samples) and a sliding window of length 16. The timing metric is defined as:

   $$
   M_{\text{STS}}[n] = \frac{\left| \sum_{m=0}^{L-1} r[n+m] \, r^*[n+m+D] \right|^2}{\left( \sum_{m=0}^{L-1} |r[n+m+D]|^2 \right)^2}
   $$

   where $D = 16$ and $L = 16$. The first index where $M_{\text{STS}}[n]$ exceeds a threshold (0.8) is taken as the coarse timing offset.

2. **Fine timing synchronization** using the LTS periodicity. An autocorrelation with delay $D = 64$ is computed over a window around the expected LTS start. The metric is similar to the STS case but with $D = 64$ and $L = 64$. The plateau of this metric gives the start of the first long symbol.

3. **Carrier frequency offset correction** (optional): The two identical halves of the LTS are used to estimate and correct any frequency offset. The phase rotation between the two halves is measured and converted to a frequency offset.

4. **Channel estimation using the LTS**. After fine timing, the receiver extracts one 64-sample long symbol (or averages both) and performs an FFT. The channel frequency response is estimated by dividing the received frequency-domain signal by the known transmitted long symbol values:

   $$
   \hat{H}[k] = \frac{Y_{\text{LTS}}[k]}{X_{\text{LTS}}[k]}
   $$

   where $Y_{\text{LTS}}[k]$ is the FFT of the received long symbol, and $X_{\text{LTS}}[k]$ is the known frequency-domain long symbol.

5. **Data extraction and CP removal**: After synchronization, the data part is reshaped into OFDM symbols of length 80, and the first 16 samples (cyclic prefix) are discarded, leaving 64 samples per symbol.

6. **FFT and equalization**: Each data symbol is transformed to frequency domain via FFT. Zero-forcing equalization is performed by dividing by the estimated channel:

   $$
   \hat{X}[k] = \frac{Y[k]}{\hat{H}[k]}
   $$

7. **QPSK demapping**: The equalized symbols are converted back to bits using hard decisions:

   $$
   b_I = \begin{cases} 0, & \Re(\hat{X}) > 0 \\ 1, & \Re(\hat{X}) < 0 \end{cases}, \quad
   b_Q = \begin{cases} 0, & \Im(\hat{X}) > 0 \\ 1, & \Im(\hat{X}) < 0 \end{cases}
   $$

## Channel Models

### AWGN

Additive white Gaussian noise is added to the received time-domain signal according to the specified SNR. For a complex baseband signal, the noise standard deviation is:

$$
\sigma = \sqrt{ \frac{P_{\text{signal}}}{2 \cdot 10^{\text{SNR}_{\text{dB}}/10}} }
$$

where $P_{\text{signal}}$ is the average power of the noiseless received signal (after multipath, before noise).

### Two-Tap Multipath Channel

The multipath channel is modeled as a linear convolution with a two-tap impulse response:

$$
h[n] = \delta[n] + a \cdot \delta[n - d]
$$

where $a$ is the gain of the delayed path (e.g., 0.5) and $d$ is the delay in samples (e.g., 10). The channel output is:

$$
y[n] = x[n] + a \cdot x[n-d]
$$

This channel is static and the delay is less than the cyclic prefix length, preserving subcarrier orthogonality after CP removal.

## Simulation Results

The modem has been validated by simulating BER versus SNR under:
- AWGN only.
- Two-tap multipath channel with perfect channel knowledge and with LTS-based channel estimation.

The resulting BER curves match theoretical expectations for uncoded QPSK in the respective channels. At high SNR, the system achieves near-zero BER, confirming the correctness of synchronization and equalization.
